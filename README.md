# 🎂 Cosmic Birthday Website 🌌

A special interactive birthday website created to celebrate someone amazing ✨  
This project is designed with a space theme, fun animations, surprises, and a magical birthday vibe.

---

## 🌟 Features

- 🎉 Animated birthday landing page  
- 🌌 Space-themed background & effects  
- 🚀 Creative transitions and surprise elements  
- 🎵 Background music (optional)  
- 🎁 Hidden messages / interactive buttons  
- 📱 Responsive design (works on mobile & desktop)

---

## 🛠 Technologies Used

- HTML5  
- CSS3  
- JavaScript
